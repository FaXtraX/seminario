MENDOZA REPORTA

Proyecto web del Trabajo Práctico N.º 2 - Seminario Nuevas Tecnologías.

Archivos:
- index.html: estructura y pantallas.
- style.css: diseño responsive.
- script.js: funcionamiento y almacenamiento mediante localStorage.

Cómo abrirlo:
1. Descomprimí la carpeta.
2. Abrí index.html con Chrome, Edge o Firefox.
3. Entrá en "Reportar" para crear un reporte.
4. Entrá en "Reportes" para consultar los datos guardados.

No necesita instalar programas ni conexión a internet para funcionar.
